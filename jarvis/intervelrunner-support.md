## 🔧 개선할 기능

- 두 페이지가 CSS를 각자 인라인으로 중복 보유 → 공용 `style.css`로 분리하면 수정 지점이 하나가 된다.
- 지원 페이지 ↔ 개인정보 처리방침 왕복 링크 부족: `privacy.html`에 지원 페이지로 돌아가는 링크가 없다.
- 호스팅 설정이 저장소에 없음(배포 URL·`CNAME`·`.nojekyll` 등 없음): App Store Connect에 등록할 지원/방침 URL을 확정하고 문서에 기록할 것.
- 영문 버전 없음: 해외 App Store 노출 시 필요할 수 있음.
- 앱 버전, 스크린샷, 사용법 등 앱 소개 콘텐츠가 없어 FAQ 위주로만 구성됨.
- `jarvis/` 폴더가 아직 git 미추적 상태 → 문서 커밋 여부 결정 필요.

## 주요 내용 요약

- **역할 분담 고지**: 운동 진행·음성 안내는 워치, 프로그램 편집·주간 계획·기록 조회는 iPhone.
- **프라이버시 핵심**: 데이터는 전부 기기 내 저장, 외부 전송·계정·광고·추적 없음. 완료 운동만 Apple 건강 앱에 기록.
- **권한 안내**: 건강 데이터(설정 → 건강 → 데이터 접근 및 기기), 위치(앱 사용 중) 경로를 양 페이지에 명시.
- **의료 고지**: 컨디션 점수·훈련부하·심박 영역은 참고용이며 진단이 아님.
